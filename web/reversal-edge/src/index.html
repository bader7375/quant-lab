Update data with Claude

Works when this page is open inside Claude. The button starts a Claude Code session on your account (it uses your plan's usage, Opus 5.5 by default). The session downloads the latest daily prices from a data provider, checks them, and writes them into this terminal. Prices are never taken from search summaries or the model's memory.

The environment must allow the data provider in its network settings (claude.ai/code → environment → Edit → Network access → Custom → add query1.finance.yahoo.com). Otherwise the session stops and tells you which host was blocked.

Automatic updates: the Routine "QuantLab daily data update" refreshes the 193 built-in Saudi stocks and TASI every Sunday to Thursday after the close (15:48 Riyadh) and notifies your phone. Run it any time from the Claude app: Routines → QuantLab daily data update → Run now. New prices show up here by themselves. The newer Saudi listings, Aramco (2222) and the US stocks in the library are not on the Routine yet: ask Claude to refresh them.

Or update by hand: download newer daily prices (Saudi Exchange website, your broker) and drop the files above. A file that overlaps the stored history is joined to it automatically, and the older prices are rescaled for bonus shares and splits.
